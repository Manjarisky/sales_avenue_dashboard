# 📊 Sales & Revenue Analysis Dashboard

An interactive dashboard built with **Python, Streamlit, Pandas, and Plotly** to analyze sales and revenue data.

## 🎯 Project Objective

The goal of this project is to analyze sales data and generate useful business insights through interactive visualizations and key performance indicators (KPIs).

## 🚀 Features

* 💰 Total Sales KPI
* 📈 Total Revenue KPI
* 📦 Total Quantity KPI
* 📈 Revenue trend over time
* 🏆 Top-performing products
* 📊 Sales by category
* 🌍 Sales by region
* 🔍 Interactive product filter
* 🏷️ Interactive category filter
* 🌎 Interactive region filter
* 📅 Date range filter
* 💡 Automatic business insights
* 📋 Filtered sales data table

## 🛠️ Technologies Used

* **Python**
* **Streamlit**

## 📊 Dashboard
![Sales & Revenue Dashboard](revenue_dashboard.png)
The dashboard provides an interactive view of sales and revenue performance.

Users can filter the data by:

* Product
* Category
* Region
* Date range

The charts and KPIs automatically update based on the selected filters.

## 📈 Business Insights

The dashboard automatically identifies:

* Top-performing product
* Highest-performing region
* Highest-performing category

This helps users quickly understand sales performance and identify areas that are performing well.

## ▶️ How to Run Locally

Clone the repository:

```bash
git clone https://github.com/Manjarisky/sales_avenue_dashboard
```

Open the project folder:

```bash
cd sales-revenue-dashboard
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

The dashboard will open in your browser.

The application is deployed using **Streamlit Community Cloud** and connected to GitHub.
